Adds a floating click-to-chat widget that allows visitors to contact a site owner through multiple messaging and communication platforms.

== Description ==

Dragwyb Click to Chat provides a floating chat widget for WordPress websites.

It allows site visitors to access multiple communication channels from a single expandable button.  
Each channel links directly to an external messaging or contact service configured by the site administrator.

The plugin includes options to control appearance, position, device visibility, and display timing.

This plugin does not collect, store, or track user data. It only outputs links that redirect visitors to third-party services.

**Features:**

* Supports multiple communication channels including WhatsApp, Facebook Messenger, Instagram, Telegram, Phone (click to call), Email, SMS, Twitter/X, and LinkedIn.
* Customization options for widget color, size, and icon style.
* Position controls for bottom-left or bottom-right placement with optional offset values.
* Device visibility settings for desktop, mobile, or both.
* Optional delay before displaying the widget.
* Lightweight implementation without external dependencies.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/dragwyb-click-to-chat` directory, or install the plugin through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Open the **Click to Chat** menu in the admin dashboard to configure available channels and widget settings.

== Frequently Asked Questions ==

= Can I add custom links? =
Currently, the plugin supports a predefined list of communication platforms. Support for custom links may be added in future versions.

= Does this plugin store or track user data? =
No. The plugin does not store cookies, track users, or collect analytics data. It only generates links to external services.
