== Description ==

**AI Chatbot & Multi-Channel Social Chat** is a high-performance **multi-channel chat and automated support WordPress plugin** designed to bridge the gap between you and your visitors. Instead of a single-link tool, this plugin provides an all-in-one **floating chat widget** that supports an intelligent AI chatbot alongside multiple messaging and social platforms in one unified, sleek interface.

The plugin features a stylish, expandable **floating button** that acts as a central communication hub. Whether you need a 24/7 **AI chatbot** to answer automated inquiries, a **social messenger redirect**, or a direct link to your professional profiles, this plugin handles various channels simultaneously with zero impact on site performance.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/dragwyb-click-to-chat` directory, or install it through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** menu.
3. Open **Click to Chat** from the WordPress admin menu.
4. Enable your AI Chatbot, configure your preferred social chat channels, and customize the widget.

== Frequently Asked Questions ==

= What is the AI Chatbot feature? =
The newly added AI Chatbot is an automated assistant that lives inside your chat widget. It can greet visitors and instantly answer common queries natively on your website without requiring the user to switch apps.

= Can I use both the AI Chatbot and the social media buttons? =
Yes! The widget is designed to be an all-in-one hub. You can feature the AI Chatbot as the primary support method while keeping social redirect buttons (like WhatsApp or Messenger) available in the expandable menu.

= What is a click to chat widget? =
A click to chat widget is a floating button that lets website visitors instantly contact you via various social messaging apps, email, or phone.

= Does this plugin support multiple chat platforms? =
Yes. Dragwyb Click to Chat is a multi-channel tool that allows you to add several different social and contact redirect buttons in one widget.

= Does this plugin store or track user data? =
No. The social redirect functionality does not store cookies or collect analytics. The AI chatbot processes queries strictly to generate responses, maintaining user privacy. 

= Is this plugin suitable for business websites and eCommerce? =
Yes. It is ideal for businesses, online stores, agencies, freelancers, and service providers looking for an omnichannel contact and automated support solution.

= Will this plugin slow down my website? =
No. The plugin is lightweight, optimized for performance, and loads minimal assets to ensure fast page speeds.
