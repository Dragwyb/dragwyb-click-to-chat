A lightweight, floating social chat widget to connect your visitors to WhatsApp, Facebook Messenger, Phone, Email, Telegram, and more.

== Description ==

Social Chat Widget is the easiest way to add a multi-channel floating contact button to your WordPress site. Let your visitors choose their preferred way to contact you directly from a simple, customizable menu.

Stop losing leads because visitors can't find your contact info. With Social Chat Widget, you're just one click away.

**Key Features:**

*   **10+ Social Channels:** Support for WhatsApp, Facebook Messenger, Instagram, Telegram, Phone (Click to Call), Email, SMS, Twitter/X, and LinkedIn.
*   **Fully Customizable:** Change the widget color, size, and icon style to match your brand.
*   **Flexible Positioning:** Place the widget on the bottom-left or bottom-right, or fine-tune with custom pixel offsets.
*   **Device Targeting:** Choose to show the widget only on Desktop, only on Mobile, or both.
*   **Trigger Settings:** Add a time delay (in seconds) before the widget appears to avoid distracting users immediately.
*   **Lightweight & Fast:** Built with clean code and no heavy dependencies to keep your site fast.

== Installation ==

1.  Upload the plugin files to the `/wp-content/plugins/social-chat-widget` directory, or install the plugin through the WordPress plugins screen directly.
2.  Activate the plugin through the 'Plugins' screen in WordPress.
3.  Use the **Social Chat** menu in the admin dashboard to configure your channels and customize the widget.

== Frequently Asked Questions ==

= Can I add my own custom link? =
Currently, the plugin supports a registered list of popular social networks. Support for custom links may be added in future versions.

= Does this plugin track user data? =
No, this plugin does not track user data or store cookies. It simply provides links to external services (like WhatsApp or Facebook).
