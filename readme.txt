A lightweight click to chat WordPress plugin that adds a floating WhatsApp chat and social chat widget for instant customer communication.

== Description ==

**Dragwyb Click to Chat** is a modern **click to chat WordPress plugin** that adds a floating chat widget to your website, allowing visitors to contact you instantly using popular messaging and communication platforms.

The plugin provides a single expandable **floating chat button** that reveals multiple contact options such as **WhatsApp chat, Facebook Messenger, Instagram, Telegram, Phone (click to call), Email, SMS, Twitter/X, and LinkedIn**.

This plugin is ideal for business websites, service providers, agencies, landing pages, and eCommerce stores that want to improve customer communication, increase engagement, and reduce friction without impacting site performance.

Dragwyb Click to Chat is built with privacy and performance in mind. It does **not** track users, store personal data, set cookies, or load third-party scripts.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/dragwyb-click-to-chat` directory, or install it through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** menu.
3. Open **Click to Chat** from the WordPress admin menu.
4. Enable your preferred chat channels and customize the widget.

== Frequently Asked Questions ==

= What is a click to chat widget? =
A click to chat widget is a floating button that lets website visitors instantly contact you via WhatsApp, social messaging apps, email, or phone.

= Does this plugin support WhatsApp chat for WordPress? =
Yes. Dragwyb Click to Chat includes full support for a WhatsApp floating chat button.

= Does this plugin store or track user data? =
No. The plugin does not store cookies, track users, or collect analytics. It only creates outbound links to third-party communication platforms.

= Is this plugin suitable for business websites and eCommerce? =
Yes. It is ideal for businesses, online stores, agencies, freelancers, and service providers.

= Will this plugin slow down my website? =
No. The plugin is lightweight, optimized for performance, and loads minimal assets.
